# Property-Based Testing Specification

## Purpose

Enforces generative property-based testing across core spatial data structures and binary wire serialization codecs to discover boundary defects, numerical anomalies, and encoding corner cases.

## ADDED Requirements

### Requirement: Binary Codec Property Roundtripping
The binary wire codec SHALL successfully roundtrip arbitrary valid packet payloads, opcode variations, sequence numbers, and floating point coordinates without panics or data corruption.

#### Scenario: Interaction packet arbitrary payload roundtrip
- **GIVEN** arbitrary generated byte vectors up to 64 KiB, arbitrary opcode numbers, sequence numbers, and timestamps
- **WHEN** encoded into a binary frame and decoded via `ClientPacket::decode_frame`
- **THEN** the decoded packet SHALL exactly match the original packet fields and payload bytes.

#### Scenario: Movement packet floating point roundtrip
- **GIVEN** arbitrary generated finite floating point positions, velocities, yaw, and pitch values
- **WHEN** serialized into binary movement frames and decoded
- **THEN** the coordinates SHALL match within single-precision floating point accuracy.

### Requirement: Spatial Octree Invariant Verification
The spatial `Octree` and `BoundingBox3D` data structures SHALL satisfy geometric invariants under arbitrary point distributions and query radii.

#### Scenario: Radius query correctness oracle
- **GIVEN** an octree populated with an arbitrary set of random 3D points
- **WHEN** a radius query is executed for arbitrary center coordinate and search radius
- **THEN** every returned entity's Euclidean distance from center SHALL be $\le$ radius
- **AND** no inserted entity with distance $\le$ radius SHALL be omitted from the query results.
